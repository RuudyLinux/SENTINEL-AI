SENTINEL VISION · Solution Demonstration Video

Script, storyboard and shot list · target length 4:45 to 5:00 · recorded on the real running system (no mock-ups, no edited screens)

Recording principles

  • Show only what the system does live. Every screen below exists in the current build.
  • Use a recorded traffic video as the primary camera source (reliable), and show the Sentinel Grid cameras only if they are connected at recording time.
  • Do not say "all 30 cameras streaming", "statewide", accuracy percentages or speed-ups on camera.
  • Screen: 1920×1080, browser at 100 % zoom, dark theme, notifications off. Voice-over recorded separately and laid over the capture.

Pre-recording setup (15 minutes before)

  • Start the stack with start.bat; confirm http://localhost:8000/api/health and the login page load.
  • Upload a traffic clip as a camera (Cameras → Add Camera → Uploaded video file), with person, vehicle and ANPR on. A clip from evidence_store/ of a grid junction works.
  • Map → Restricted Zones: create a HIGH zone on that camera (full frame).
  • Watchlists: add one plate known to appear in the clip, so a watchlist alert can fire.
  • Open one existing incident in a second tab as a fallback if a live alert is slow to appear.
  • Log in once beforehand so model weights are warm.
Honesty guard for the narrator. If the grid cameras are degraded during recording, say so in one line ("some grid cameras are reconnecting; Self-Heal is handling it") rather than cutting around it. It demonstrates the health monitoring truthfully.

Fallbacks if something is slow on the day

  • No new alert within 30 s: open the most recent existing zone-entry alert and say "here is one raised earlier today by the same rule".
  • Plate not read on the demo clip: open an existing vehicle from Vehicles → ANPR that has a corroborated read.
  • Grid cameras degraded: keep them on screen for the Self-Heal segment; they illustrate reconnecting honestly.

Post-production

  • Lower-thirds with the feature name at each segment (e.g. "AI detection · YOLO11 + ByteTrack").
  • No speed-ups of detection footage; cut only between segments. Keep the on-screen clock visible where it appears.
  • End card: project name, repository URL, "Current implementation shown; scaling roadmap in the architecture document".
